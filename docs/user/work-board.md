# Work board

The **Trabalho** page (sidebar → Trabalho) shows what you are building: each project, the modules inside it, and the threads working on each module.

- **Modules** nest freely. Add one with **+ Módulo**, or **Adicionar submódulo** from a module's menu.
- **Status is yours.** Click a status to change it (*Ideia*, *Em andamento*, *Esperando*, *Finalizado*). *Esperando* asks what you are waiting on. Agents can read the board and suggest modules, links and notes, but never change status.
- **Due dates** are optional. **Vence este mês** shows what is due or overdue this month.
- **Threads:** start one from a module with **Nova thread aqui**. It opens with the module's path and note in the composer. You can also link a thread in a project from the **Módulo** chip in its header. A thread belongs to one module at a time.
- **Árvore or Kanban:** the toggle at the top switches views; dragging a card across columns changes its status.
